# TownPass 專案背景

使用者要求詳讀並記住《2026 城市通入門指引》。後續規劃與開發城市通微服務時，先參閱 [TOWNPASS_BRIEFING_NOTES.md](TOWNPASS_BRIEFING_NOTES.md)。

筆記保留簡報的競賽規則、建議、設計規範與交件要求。第三方版本、授權、模型與平台狀態仍須以實際原始碼和官方來源查核；勿將簡報記載稱為已獨立驗證。

## 設計方法參考

使用者於 2026-10-27 要求學習 https://github.com/elayadesign/ai-design-skills 。已閱讀 landing-page-design 與 design-to-motion 的主要流程與檢查項目，作為參考，並未安裝為全域技能。

- 頁面設計先釐清受眾、使用情境與主要行動，再安排資訊、文案與視覺；分區實作、檢查手機閱讀與完整互動狀態（焦點、載入、空資料、錯誤與復原）。
- 動畫展示先還原靜態設計，再規劃載入次序與有意義的視覺敘事；網站保留可存取的 HTML 文字，區塊離開畫面時暫停動畫，減少動態偏好下提供完整靜態內容。展示動畫的慢速循環不可直接套用至公共服務操作流程。
- 動畫輸出檢查靜態一致性、裁切／溢出、首尾銜接與殘影；影片採可重現的逐格擷取流程。
- TownPass UI Kit、專案 tokens 與無障礙要求優先；不套用參考庫的字體黑名單、固定 Tailwind 字級、指定圖示庫、強制標語動畫或行銷頁結構。
- 參考庫的擬真範例內容僅能作明確標示的示意資料，不得虛構成效數據、客戶或見證當成真實證據。
